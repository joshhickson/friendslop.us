Privacy

friendslop has no accounts, no ads, no analytics and no cookies. Here is everything it does see, how long it keeps it, and who else is in the path.

Last updated 28 October 2026.

The short version

  • The name you type is shown to the other players in your room and saved in your own browser.
  • Rooms, passwords, chat and scores live in the server's memory while the room is open, and are gone when it closes.
  • Your IP address is used, in memory only, to slow down spam and password guessing. The server never writes it to its log.
  • Games shared by link are made by other people. A game can see your IP address, the way any website can.
  • Nothing is sold, shared for advertising or used to build a profile of you.

Who runs it

friendslop.us and play.friendslop.us are run by Josh Hickson. Questions about this page, or a request to delete something, go to contact@joshuahickson.org.

friendslop is open source, so anyone can run their own copy. This page covers only the two sites above. A server somebody else runs, including one shared with npm run tunnel, is theirs, and so is what it keeps.

friendslop.us

This site is a set of plain pages. It sets no cookies, runs no analytics and has no forms that send anything to us. The room code box and the game link box only send you to play.friendslop.us with what you typed in the address.

Everything on it, the fonts included, comes from this one site. GitHub Pages serves it, and GitHub logs requests for security under its privacy statement.

play.friendslop.us

What you give it

  • Your name. The other players in your room see it, and it can appear in chat, on the scoreboard and in the line that announces the result of a match.
  • Room passwords and chat. Held in the server's memory only, for as long as the room is open. They are never written to disk or to the logs.

What it keeps, and for how long

  • Rooms, teams, scores and stats stay in memory until the room closes, either when its last person leaves or after it sits idle. A restart of the server clears everything.
  • Your IP address is held in memory to limit how many connections and rooms one address can open and to lock out repeated wrong passwords. Those counters clear themselves within minutes, and the address is never written to the log.
  • The server's log records when a room is created, with the room code, the game and whether it has a password. It also records when matches start and end, and the result line, which can include a player's name. The service that hosts the server keeps these logs for seven days.
  • A daily traffic total for the whole server, with no per-person detail.

What it saves in your browser

No cookies. The app keeps a few things in your browser's own storage. Only the name and the seat token are ever sent to the server, when you join a room.

  • the name you last used, so you don't type it again;
  • a seat token for the room you're in, so a refresh puts you back in your seat (cleared when you close the tab);
  • which game repos you've said yes to on the first-look warning, and which game banners you closed this session.

Clearing your browser's site data for play.friendslop.us removes all of it.

Games shared by link

Anyone can host a game from a public GitHub repo, and nobody reviews it first. When you play one:

  • its files load from jsDelivr, a public CDN, which sees your IP address under its privacy policy;
  • the host's browser asks GitHub which commit a link points to;
  • the game runs in a sandboxed frame that can't read friendslop's storage or pages. It can still reach an outside server, which would see your IP address, and it can show anything on screen. Never type a password into a game.

That's why you see a warning before an unreviewed game first loads. What a game made by somebody else does with your data is up to its maker. An unreviewed game's banner has a report link, which opens a public GitHub issue.

Who else is in the path

  • Render hosts the game server and keeps its logs.
  • Cloudflare carries Render's traffic, and routes email sent to the contact address.
  • GitHub hosts this site, the code and the issues.
  • jsDelivr serves the files of games shared by link.

Each keeps its own logs under its own policy. Render and Cloudflare carry every connection to the game server, so their records can include your IP address even though friendslop's own log does not.

Issues and email

GitHub issues and pull requests are public, so don't put anything private in them. Email to the contact address is read by Josh, used only to answer you, and deleted when you ask.

Children

friendslop isn't made for children under 13 and doesn't ask anyone's age. If you think a child has sent us personal information, email the contact address and it will be deleted.

Asking, and changes

You can ask what we hold about you, or ask for it to be deleted, at contact@joshuahickson.org. Since there are no accounts, the most there will be is a match result with your name in it from the last seven days, or an email you sent.

When this page changes, the date at the top changes too, and every earlier version is in the site's history on GitHub.
