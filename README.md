# friendslop.us

The one-page teaser for friendslop, served by GitHub Pages at https://friendslop.us.

The project itself lives at **https://github.com/joshhickson/friendslop**.

- Plain HTML pages with one `style.css` and one `site.js`: no build step and nothing loaded from another site.
- `fonts/` holds the two typefaces, the same files the play app serves, with their licences.
- `CNAME` tells GitHub Pages which domain to serve.
