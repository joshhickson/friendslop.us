In alpha

Bots join like players

Programs outside the game connect to a room the way a person does, so anything that can connect can play. The built-in bots join the lobby like players too, and run in the host's browser with the game.

In progress

Built-in bots

The host adds as many as they like. They fill empty slots, so you can test a game alone at 2am and still have someone to shoot.

Planned

Your code as a bot

Write a bot in whatever language you like. If it speaks the protocol, it can join a room, pick a team and play.

Planned

AI agents as players

Point an AI agent at a room. It can call plays, guard the flag, talk trash in chat, and lose gracefully, or not.

Why build bots this way

Fast bots and smart bots

Moving and aiming has to happen many times a second, which is a job for plain game code. Deciding what to do next can be slower, which is where an AI agent fits.

friendslop keeps the two apart, so an AI never has to aim and a bot never has to wait for one.

One door for everyone

People and outside programs come through the same door: a room code, a name, and a server that checks every message it relays. The host's rules decide what those messages mean, and a bot you write gets no more say than a player does.

Built-in bots are the exception. They run in the host's browser next to the game, so they're exactly as honest as the host. A full lobby is still one click away.
