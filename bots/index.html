Why build bots this way

Fast bots and smart bots

Moving and aiming has to happen many times a second, which is a job for plain game code. Deciding what to do next can be slower, which is where an AI agent fits.

friendslop keeps the two apart, so an AI never has to aim and a bot never has to wait for one.

One door for everyone

People, built-in bots and outside programs all come through the same door, and the server checks every move the same way.

That means a bot can't cheat any more than a player can, and a full lobby is always one click away.
