Multiplayer in one command. Arguments in two minutes.

friendslop is a kit for making small, chaotic multiplayer games. Rooms, lobbies, bots and hosting are already done, so you only build the fun part.

Play the demo Make your own game

The demo is Control Points, ten a side in your browser. Bots take every empty seat, so you can play alone or send your friends the room link. You need a keyboard and mouse.

Your game runs in the host's browser and friendslop only passes the messages along. Nobody reviews it first, so the host could change the score.

Multiplayer is usually where a game idea dies: rooms, lobbies, netcode, hosting and cheaters. friendslop does that part once, for every game you make.

Make your first game

You need a free GitHub account, Git and Node.js 20 or newer. Your game lives in your own copy of the friendslop repo, and the link to its folder is all your friends need.

Hand it to your AI agent

Paste this into Claude Code, Cursor or any coding agent that can run commands. It sets everything up, then asks you what game you want.

Set me up to make a multiplayer game with friendslop.

1. Fork https://github.com/joshhickson/friendslop to my GitHub
   account and clone my fork. With the GitHub CLI that's:
   gh repo fork joshhickson/friendslop --clone
   If you can't fork it, tell me to press Fork on GitHub.
2. Read docs/making-a-game.md before writing any code.
3. In the clone, run: npm run new-game -- my-game "My Game"
4. Ask me what game I want to make, and ask follow-up
   questions until you know how it plays. Then build it
   in games/my-game.
5. Run npm run play and check it in two browser windows.
6. Commit and push to my fork.
7. Give me the link to the game folder. It looks like
   https://github.com/MY-USERNAME/friendslop/tree/main/games/my-game

Or do it yourself

  1. Fork it

    Press Fork on the friendslop repo, then copy your fork to your computer.

    git clone https://github.com/YOU/friendslop cd friendslop

  2. Start a game

    This makes games/my-game from the starter, a room where everyone is a dot, and opens it in your browser. Open a second window to play against yourself.

    npm run new-game -- my-game "My Game" npm run play

  3. Add your rules

    The rules go in server.js and the screen in client/index.js. Rooms, lobby, teams and networking are already done. The game guide shows where everything goes.

  4. Push and paste

    Push to your fork, open the game's folder on GitHub and copy the address. Paste it into Got a game on GitHub? at the top and send your friends the room link.

    git add games/my-game git commit -m "My game" git push

Questions people keep asking

Can I play it yet?

Yes. The Control Points demo is live, and bots fill the empty seats. To play a game of your own, make one on the starter, push it to your fork and paste its folder link into the box at the top. Your friends get a room link and nobody installs anything.

Do I have to use JavaScript?

For the alpha, yes. After that, no: the plan is a documented protocol any language can speak. More on the protocol page.

What does friendslop mean?

The kind of cheap, messy co-op game that's only fun because your friends are in it. That's the whole genre this is for.

Will it be free?

Yes. The kit is free and open under the Apache-2.0 license, and rooms on play.friendslop.us cost nothing. You need a free GitHub account to share a game. Your friends need nothing but the link.

Can I build with an AI coding tool?

Yes, and it's a good fit. A game is one folder with clear hooks and a guide to read, so tools like Claude Code or Cursor know where your rules go. Copy the agent prompt to get started.

Can I help build friendslop?

Please do. Pull requests are welcome for games, fixes, docs and the kit itself. Here's how.
