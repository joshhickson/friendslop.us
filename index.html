What's in the box

The boring parts of a multiplayer game, done once, so every new idea starts at the fun part.

  • #
    Rooms with a code and a passwordMake a room, send the code to the group chat, keep the randoms out.
  • >
    A lobby where the host runs the showPick teams, see who's in, start the match when everyone stops talking.
  • +
    Game modes that snap inEach game is an add-on to the same foundation. Shooter today, something stupider tomorrow.
  • @
    Bots that join like playersThey fill empty slots, and they connect the same way people do, so your own code can drive one.
  • ~
    Host from your own PCShare a link and friends join from anywhere, with no router settings to touch.
  • *
    Runs in a browserYour friends click a link. Nobody installs anything.

Questions people keep asking

Can I play it yet?

Not yet. It's being built right now. Watch the repo on GitHub to see the code land.

What does friendslop mean?

The kind of cheap, messy co-op game that's only fun because your friends are in it. That's the whole genre this is for.

Will it be free?

Yes. It's a free, open kit under the Apache-2.0 license, and you host it yourself. No store page, no account to make.

Why does one theme look broken?

That's the missing-texture checkerboard every game developer has seen at 3am. It felt right.
