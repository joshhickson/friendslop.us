Roadmap

What the alpha already does, what's next, and what comes after that. It changes as the alpha does.

Done, in testing

  • Rooms with a code and a password
  • A lobby with teams and scores
  • Host controls, chat, scoreboard and reconnects
  • Hits, flags and score are decided by your own server, or by the host's browser when a game is shared by link
  • Local-only until you share a link
  • Hosting for friends on other networks
  • Built-in bots and spectating
  • Games shared by a GitHub link, played at play.friendslop.us
  • A new-game template, a how-to guide and automated tests
  • The first public code drop
  • Control points, the first demo, with bots that play
  • One look across the site and the game screens
  • Packed messages, so a match sends about an eighth of the data
  • Docs on this site

Up next

  • Testing the demo in more browsers
  • Easier ways to bring in a game you already made

After that

  • Games made by other people on the games page
  • The written protocol spec
  • Touch controls for phones
  • Bots written in any language
  • AI agents as players
  • A Rust and WebAssembly client
  • The first friendslop jam
