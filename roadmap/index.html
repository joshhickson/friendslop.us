Roadmap

What the alpha already does, what's being built now, and what comes after. It changes as the alpha does.

Done, in testing

  • Rooms with a code and a password
  • A lobby with teams and scores
  • Host controls, chat, scoreboard and reconnects
  • The server decides hits, flags and score
  • Local-only until you share a link
  • Hosting for friends on other networks
  • Capture the flag
  • A tiny demo game and a new-game template
  • A how-to guide and automated tests

In progress

  • Built-in bots
  • A respawn wait with spectating
  • Control points
  • The first public code drop

After that

  • Docs
  • The written protocol spec
  • Touch controls for phones
  • Bots written in any language
  • AI agents as players
  • A Rust and WebAssembly client
  • The first friendslop jam
